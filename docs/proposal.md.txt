# Thesis Proposal: Distributed E-Commerce Platform Based on CQRS and Event-Driven Architecture

## 1. Попередня робоча назва проєкту
* **Українською:** Розподілена платформа електронної комерції цифрових товарів та курсів на основі патерна CQRS та подієво-керованої архітектури
* **English:** Distributed E-Commerce Platform for Digital Goods and Courses Based on CQRS and Event-Driven Architecture

---

## 2. Актуальність та проблематика
Сучасні платформи реалізації цифрового контенту та освітніх курсів під час пікових навантажень (масові розпродажі, одночасні релізи) стикаються з гострим ресурсним конфліктом між операціями читання каталогу та запису транзакцій (оформлення замовлень, генерація прав доступу). У традиційних монолітних підходах зі спільною реляційною базою даних це викликає каскадні блокування (deadlocks), стрімке зростання затримок (high latency) та деградацію продуктивності всієї системи.

Інженерна складність полягає в забезпеченні високої пропускної здатності на читання за умов збереження абсолютної транзакційної цілісності та гарантованої доставки цифрових активів. Проблема вирішується шляхом проєктування розподіленої мікросервісної архітектури на базі патерна CQRS (Command Query Responsibility Segregation). Це дозволяє незалежно масштабувати моделі читання і запису, синхронізуючи стан через асинхронний брокер повідомлень із досягненням принципу остаточної узгодженості (Eventual Consistency).

---

## 3. Сформована ідея продукту
Розробка хмароорієнтованої розподіленої платформи електронної комерції цифрових освітніх матеріалів та IT-курсів. Архітектура передбачає фізичне та логічне розділення операцій мутації даних (команд) і вибірки даних (запитів), використання брокера повідомлень як магістралі подій, а також автоматизовану видачу цифрових прав доступу без затримок у режимі реального часу.

---

## 4. Детальний опис функціоналу (Core Features)
1. **Модуль каталогу та пошуку (Query Side):** Високопродуктивна вибірка даних курсів, фасетна фільтрація за категоріями й тегами з використанням багаторівневого кешування для мінімізації часу відповіді сервісу.
2. **Модуль замовлень та транзакцій (Command Side):** Ізольована бізнес-логіка оформлення покупок цифрових товарів, що генерує системні доменні події без блокування читання каталогу.
3. **Асинхронний конвеєр обробки подій (Event-Driven Pipeline):** Використання брокера повідомлень для гарантованої передачі подій (`OrderCreated`, `AccessGranted`) між мікросервісами з підтримкою дедуплікації та ідемпотентності консюмерів.
4. **Модуль цифрового доступу (Asset Delivery Service):** Автоматизована видача доступу до придбаного курсу відразу після верифікації транзакції платіжною системою.
5. **Сервіс автентифікації та авторизації (IAM Service):** Безпечна авторизація клієнтів і авторів на основі токенів JWT з розмежуванням прав (RBAC).
6. **Панель адміністратора та моніторингу (Admin Dashboard):** Інтерфейс управління каталогом, перегляд розподілених логів обробки подій та контроль працездатності мікросервісів.
7. **Контейнеризація та оркестрація інфраструктури:** Повна ізоляція сервісів, баз даних і брокера в Docker-контейнерах із маршрутизацією трафіку через API Gateway.

---

## 5. Технологічний стек та інструментарій
* **Мови програмування:** TypeScript, SQL
* **Бекенд та фреймворки:** Node.js, NestJS
* **Архітектурні патерни:** CQRS, Event-Driven Architecture, Microservices, Transactional Outbox
* **Брокери повідомлень:** Apache Kafka
* **Бази даних та сховища:**
  * *Write Model:* PostgreSQL (ACID-транзакції для замовлень та білінгу)
  * *Read Model & Cache:* Redis (кешування гарячих вибірок та read-моделей)
* **Фронтенд:** React, TypeScript, Tailwind CSS
* **DevOps та інфраструктура:** Docker, Docker Compose, Nginx (API Gateway)
