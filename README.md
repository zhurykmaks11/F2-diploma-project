# Distributed E-Commerce Platform for Digital Goods and Courses

> Кваліфікаційний бакалаврський проєкт зі спеціальності **121 «Інженерія програмного забезпечення» (F2)**[cite: 1, 15].  
> **Тема:** Розподілена платформа електронної комерції цифрових товарів та курсів на основі патерна CQRS та подієво-керованої архітектури[cite: 9].

---

## 🏗 Архітектурний огляд (System Architecture)
Проєкт реалізує хмароорієнтовану мікросервісну архітектуру з повним логічним та фізичним розділенням операцій мутації даних (**Command Side**) та їх вибірки (**Query Side**) за патерном **CQRS**[cite: 9]. 
Для забезпечення асинхронної міжсервісної взаємодії та досягнення остаточної узгодженості даних (**Eventual Consistency**) використовується розподілений брокер повідомлень **Apache Kafka**[cite: 9].

* **Write Model (OLTP):** PostgreSQL (гарантія ACID-транзакцій для замовлень та білінгу)[cite: 9].
* **Read Model & Cache:** Redis (високопродуктивне кешування гарячих вибірок каталогу та read-моделей)[cite: 9].
* **Event Bus:** Apache Kafka (гарантована доставка подій за патерном *Transactional Outbox*)[cite: 9].

## 📊 Нефункціональні вимоги (NFRs Matrix)
| Категорія | Параметр / Метрика | Цільове значення |
| :--- | :--- | :--- |
| **Throughput** | Цільова пропускна здатність системи | $\ge 600\text{ RPS}$[cite: 27] |
| **Latency ($p95$)** | Час відгуку Query API (каталог) | $\le 120\text{ мс}$[cite: 27] |
| **Latency ($p95$)** | Час відгуку Command API (замовлення) | $\le 250\text{ мс}$[cite: 27] |
| **Consistency** | Модель узгодженості даних | Eventual Consistency через Kafka[cite: 9, 27] |
| **Reliability** | Гарантія доставки повідомлень | At-Least-Once + Idempotency Key (Redis)[cite: 27] |
| **Security** | Автентифікація та шифрування | OAuth 2.0, RS256 JWT, TLS 1.3[cite: 27] |
