# Distributed E-Commerce Platform for Digital Goods and Courses

> Кваліфікаційний бакалаврський проєкт зі спеціальності **121 «Інженерія програмного забезпечення» (F2)**.  
> **Тема:** Розподілена платформа електронної комерції цифрових товарів та курсів на основі патерна CQRS та подієво-керованої архітектури.

---

## 🏗 Архітектурний огляд (System Architecture)
Проєкт реалізує хмароорієнтовану мікросервісну архітектуру з повним логічним та фізичним розділенням операцій мутації даних (**Command Side**) та їх вибірки (**Query Side**) за патерном **CQRS**. 
Для забезпечення асинхронної міжсервісної взаємодії та досягнення остаточної узгодженості даних (**Eventual Consistency**) використовується розподілений брокер повідомлень **Apache Kafka**.

* **Write Model (OLTP):** PostgreSQL (гарантія ACID-транзакцій для замовлень та білінгу).
* **Read Model & Cache:** Redis (високопродуктивне кешування гарячих вибірок каталогу та read-моделей).
* **Event Bus:** Apache Kafka (гарантована доставка подій за патерном *Transactional Outbox*).

Згідно з інженерними стандартами, документація проєкту зберігається безпосередньо в репозиторії поруч із кодом:
* `/docs` — офіційна пояснювальна записка та технічна документація проєкту:

  * [`1_analysis.md`](docs/1_analysis.md) — Аналіз предметної області (As-Is/To-Be), функціональні (Core Features) та нефункціональні вимоги (NFRs), конкурентний аналіз аналогів.
  * `2_design.md` — Архітектурне проєктування (C4 Model, UML-діаграми, схеми БД).
  * `3_implementation.md` — Програмна реалізація критичних вузлів, інструментальний аудит та результати тестування.
  * `4_conclusions.md` — Загальні висновки до проєкту.
* `/src` — вихідний код мікросервісів та клієнтської частини.

## 🚀 Технологічний стек (Tech Stack)
* **Мови програмування:** TypeScript, SQL
* **Бекенд:** Node.js, NestJS
* **Брокер повідомлень:** Apache Kafka
* **Бази даних та сховища:** PostgreSQL, Redis
* **Фронтенд:** React, TypeScript, Tailwind CSS
* **Інфраструктура та DevOps:** Docker, Docker Compose, Nginx (API Gateway)
